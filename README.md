# Refrigerator Net Storage Volume Calculator

A web‑based parametric calculator that estimates the **net storage volume** of a refrigerator from external cabinet dimensions and internal layout configurations.  
Built for product designers and engineers during the concept design phase.

## Features
- Input external cabinet dimensions (H×W×D) and per‑face wall/insulation thicknesses
- Define up to 8 compartments (fresh food, freezer, convertible) via horizontal/vertical dividers
- Add internal fittings: shelves, drawers, door bins
- **Three volume outputs simultaneously:**  
  - Gross Volume  
  - Egyptian Net Volume (ES 3794)  
  - IEC Net Volume (IEC 62552)
- Results in liters and cubic feet, with per‑compartment breakdown
- Save/load configurations (JSON) and export results (CSV)
- Simple block‑diagram schematic of the layout
- Side‑by‑side comparison of two saved configurations

## Technology Stack
- HTML / CSS / JavaScript (vanilla, no framework)
- Runs entirely in the browser – no installation required
