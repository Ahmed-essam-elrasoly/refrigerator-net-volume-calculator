### Extracting Full Macro Code

To extract the actual VBA code, use one of these methods:


1. **Open in Excel**: Press `Alt+F11` to view/edit macros

2. **Use oletools**: `python -m oletools.vba_extract original.xlsm > macros.vba`

3. **Manual export**: In Excel VBA editor, right-click modules → Export File
